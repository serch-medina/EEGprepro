# EEGprepro
Pipeline for EEG signal preprocesing using matlab and python. Desgined for Neuroscience Division of Institute of Celular Physiology (IFC - UNAM)
# Organización y uso
Antes de utilizar véase también la siguiente sección **Consideraciones**. Crea la carpeta `data`, en ella, coloca los archivos `.hdf5` 'crudos'. A continuación se debe correr el script nombrado `pre_process_evthg.m`. Al ejecutarse el script hará que salten ventanas para indicar el número de canal para importar eventos. Basta con darle en `OK` cada vez que salte la ventana para añadir eventos desde un canal. **No** hay que colocar nada en esos campos, basta con darle en `OK`. Posterior a eso el programa se encargará de exportar el resto de archivos requeridos por `extraer_datos.py`. Toma en cuenta que por la naturaleza de los datos de electroencefalograma (EEG), el preprocesamiento de esta primera etapa puede ser algo tardado. Ten paciencia y sólo monitorea que no surja ningún error. 
Luego de exportar los datos con `extraer_datos.py`, (el cual por cierto puede configurarse para exportar datos con secciones de ensayos eliminados cortadas o no, esto se realiza directamente desde `pre_process_evthg.m`), hay que revisar los archivos de registro que se encuentran en la carpeta de `registros/` que se creará automáticamente al ejecutar por primera vez el preprocesamiento. En dicho archivos, se guardan los datos que deben de introducirse en el script `correr_ICA.m` con el fin de extraer las componentes de ICA de las señales filtradas.
# Consideraciones
1. Se guarda un archivo comprimido que contiene la biblioteca de eeglab para MATLAB, esto con el fin de evitar descargarlo, y mantener la compatibilidad del código con la version requerida. Hay que descomprimir este archivo.
2. El código esta asociado a un archivo de proyecto, es necesario iniciar el mismo desde la interfaz de MATLAB para agregar al path todos los archivos requeridos para su ejecución
3. Para correr los programas de python se requiere que el intérprete global tenga instaldas las paquetería de `numpy`, `matplotlib` ,`pandas` y `scipy`.
