# EEGprepro
Pipeline for EEG signal preprocesing using matlab and python. Desgined for Neuroscience Division of Institute of Celular Physiology (IFC - UNAM)
# Organización y uso
Antes de utilizar véase también la siguiente sección **Consideraciones**. Coloca los archivos `.hdf5` 'crudos' en la carpeta de `data`. A continuación, se debe correr el script nombrado `pre_process_evthg.m`. Al ejecutarse el script hará que salten ventanas para indicar el número de canal para importar eventos. Basta con darle en `OK` cada vez que salte la ventana para añadir eventos desde un canal. **No** hay que colocar nada en esos campos, basta con darle en `OK`. El programa se encargará de exportar el resto de archivos requeridos por `extraer_datos.py`. Toma en cuenta que por la naturaleza de los datos de electroencefalograma (EEG), el preprocesamiento de esta primera etapa puede ser algo tardado. Ten paciencia y sólo monitorea que no surja ningún error. 
Luego de exportar los datos con `extraer_datos.py`, (el cual puede configurarse para exportar los datos de actividad con secciones recortadas, correspondientes a ensayos eliminados por no encontrarse íntegros. Esto se realiza directamente desde `pre_process_evthg.m`, cambiando los argumentos que se le pasan al módulo de python. Para más información léase su documentación), hay que revisar los archivos de registro que se encuentran en la carpeta de `registros/` que se creará automáticamente al ejecutar por primera vez el preprocesamiento. En dichos archivos, se guardan los datos que deben de introducirse en el script `correr_ICA.m` con el fin de extraer las componentes de ICA de las señales filtradas.
# Consideraciones
1. Se guarda en un archivo comprimido la biblioteca de eeglab para MATLAB, esto con el fin de evitar su descarga y mantener la compatibilidad del código con la versión con la que fue escrita. Hay que descomprimir este archivo.
2. El código esta asociado a un archivo de proyecto, es necesario inicializar el mismo desde la interfaz de MATLAB para agregar al path todos los archivos requeridos para la correcta ejecución del código de pre procesamiento.
3. Para correr los programas de python se requiere que el intérprete global de python tenga instaladas las paqueterías de `numpy`, `matplotlib` ,`pandas` y `scipy`. El correcto funcionamiento del proyecto depende de esto. Se requiere cautela si se trabaja con un gestor de paquetes como `conda`.
4. Antes de ejecutar `pre_process_evthg.m`, debe de instalarse el plugin para `eeglab`: `loadhdf5`, en su versión 1.1 (preferentemente, no se ha probado comportamiento con otras versiones). Esto se puede realizar desde el menu de *File -> Manage EEGLAB Extensions*.
